# Cockpit Dessin · « Réhabilitation »

Atelier de dessin comme outil de pensée et de récit pour la transition. Contient la **carte de mission interactive** (les trois passes, le cadre « 3ème vision »), le **plan actionnable** du week-end, le **mémo** de cadrage, et les deux **projets** reliés (rénovation, énergie). Conçu pour être **opérable depuis l'iPhone** via ce dépôt Git, sur le même modèle que le cockpit LED 30k.

## Piloter depuis ton iPhone

Deux modes, comme pour le cockpit LED.

1. **Voir et utiliser la carte** : ouvre l'URL GitHub Pages de ce dépôt dans Safari, puis « Partager » puis « Sur l'écran d'accueil ». La carte de mission devient une icône plein écran, avec chronos, dé et vibrations. C'est l'outil que tu lances pendant une séance.
2. **Faire évoluer le cockpit** : ouvre ce dépôt dans **Claude Code mobile** (connecté à ton GitHub). Depuis le téléphone tu peux demander de retoucher la carte (`carte_mission_rehabilitation.html` ou `index.html`), d'ajuster le plan, d'avancer les projets.
3. **Lire au calme** : les fichiers `.md` se lisent directement dans l'app GitHub, en markdown propre.

## Contenu

- `index.html` · la carte de mission (servie par GitHub Pages). Copie de `carte_mission_rehabilitation.html`.
- `PLAN_WEEKEND.md` · ce qui est actionnable dès demain et à creuser ce week-end.
- `MEMO_dessin_3eme_vision.md` · le cadrage : 3ème vision, trois passes, captation puis révélation.
- `projet_renovation_developpement.md` (+ `.docx`) · le process de développeur, le cas d'étude.
- `projet_energie_sport_chaleur.md` (+ `.docx`) · l'idée énergie, état de l'art et verdict chiffré.

## Démarrer

Commence par `PLAN_WEEKEND.md`. Vendredi : mettre la carte sur le téléphone et partir en chasse. Week-end : le procès, puis le verdict au calque et l'amorce du cas d'étude.
